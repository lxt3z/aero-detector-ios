# Детектор АЭРО — iOS-приложение (.IPA)

Нативное приложение-обертка для сайта [Детектор АЭРО (detector-aero.ru)](https://detector-aero.ru/) на языке Swift с поддержкой:
- **Полноэкранного режима без рамок браузера**;
- **Передачи геолокации** (отображение вашего местоположения на карте БПЛА);
- **Pull-to-refresh** (потяните экран вниз для мгновенного обновления радара);
- **Индикатора загрузки** карты;
- **Экрана при потере связи** с возможностью повторить подключение;
- **Открытия внешних ссылок** (Telegram и др.) в стандартном браузере Safari.

## Как бесплатно собрать `.ipa` за 2 минуты (без Mac и без установки Xcode)

Так как для сборки `.ipa` требуется macOS, в репозиторий уже встроен **GitHub Actions** — он бесплатно собирает готовый `.ipa` файл на серверах Apple в облаке.

### Шаг 1. Загрузите этот проект на GitHub
1. Создайте бесплатный репозиторий на [GitHub](https://github.com/new) (можно публичный или приватный).
2. Загрузите файлы этого проекта в репозиторий (через Git или перетаскиванием файлов в браузере):
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/aeromap.git
   git push -u origin main
   ```

### Шаг 2. Скачайте готовый `.ipa`
1. На странице вашего репозитория на GitHub перейдите во вкладку **Actions**.
2. Вы увидите запустившийся процесс **Build iOS IPA** (он занимает около 1-2 минут).
3. Когда появится зеленая галочка, нажмите на название сборки.
4. В самом низу в блоке **Artifacts** нажмите на **DetectorAero-IPA** — скачается архив с готовым файлом `DetectorAero.ipa`.

## Как установить `.ipa` на iPhone с Windows

Так как iOS защищена от установки произвольных приложений, выберите любой удобный инструмент для Windows:

### Вариант 1. Через Sideloadly (Самый простой и популярный для Windows)
1. Скачайте бесплатную программу [Sideloadly](https://sideloadly.io/) на компьютер с Windows.
2. Подключите iPhone к компьютеру через USB-кабель (нажмите «Доверять этому компьютеру» на экране телефона).
3. Запустите Sideloadly:
   - В поле **iDevice** появится ваш подключенный iPhone;
   - Перетащите файл `DetectorAero.ipa` в окно Sideloadly;
   - В поле **Apple ID** введите вашу учетную запись Apple (нужна для создания бесплатной личной подписи приложения);
   - Нажмите **Start**.
4. После завершения на экране iPhone появится иконка «Детектор АЭРО».
5. **Перед первым запуском на iPhone**: зайдите в *Настройки -> Основные -> VPN и управление устройством*, найдите ваш Apple ID и нажмите **«Доверять»**.

> *Примечание*: Бесплатная подпись Apple действует 7 дней. Если компьютер и iPhone находятся в одной Wi-Fi сети, Sideloadly умеет обновлять приложение автоматически по Wi-Fi.

### Вариант 2. Через TrollStore (Если поддерживается)
Если у вас установлена iOS 14.0 — 17.0 с установленным TrollStore:
- Просто отправьте файл `DetectorAero.ipa` на iPhone (через Telegram/AirDrop/iCloud) и откройте его через TrollStore. Приложение установится навсегда без ограничений по времени.

## Локальная сборка на Mac (при наличии)

Если у вас или ваших знакомых есть компьютер Mac с установленным Xcode:
1. Установите генератор проектов:
   ```bash
   brew install xcodegen
   ```
2. Сгенерируйте файл проекта:
   ```bash
   xcodegen generate
   ```
3. Откройте появившийся файл `DetectorAero.xcodeproj` в Xcode, выберите ваш iPhone и нажмите **Run** (Cmd + R).
